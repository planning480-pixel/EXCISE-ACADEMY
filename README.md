# Excise Academy

แหล่งเรียนรู้กลางของกรมสรรพสามิต: 29 ห้องเรียนใน 5 หมวด (พื้นฐาน · กฎหมาย พ.ร.บ. 2560 · สินค้า · บริการ · นโยบายและอนาคต) พร้อมเครื่องคำนวณภาษี แบบทดสอบท้ายห้อง และระบบถาม Expert

เนื้อหาตั้งต้นสรุปจาก 2 เอกสาร (ข้อมูล ณ มี.ค. 2569):
- บทบาทและภารกิจกรมสรรพสามิต — สำนักแผนภาษี
- พ.ร.บ.ภาษีสรรพสามิต พ.ศ. 2560 — สำนักกฎหมาย

## เริ่มใช้งาน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
```

สร้างไฟล์ `.env.local` (ไฟล์นี้ไม่ถูกเก็บใน Git):

```
SESSION_SECRET=ข้อความสุ่มยาวอย่างน้อย 32 ตัวอักษร
EXPERT_DEFAULT_PASSWORD=รหัสผ่านเริ่มต้นของบัญชีผู้เชี่ยวชาญ
ANTHROPIC_API_KEY=
```

```bash
npm run dev
```

เปิด http://localhost:3000

คำสั่งอื่น: `npm run build` · `npm start` · `npm test` (ทดสอบสูตรคำนวณเทียบตัวอย่างในสไลด์) · `npm run lint`

## โครงสร้าง

| ที่อยู่ | หน้าที่ |
|---|---|
| `content/rooms/*.ts` | เนื้อหา 29 ห้อง แบบทดสอบ และประเด็น "รอตรวจ" |
| `content/rates.ts` | อัตราภาษีทั้งหมด **แก้ที่นี่ที่เดียว** ตารางในห้องเรียนและเครื่องคำนวณจะเปลี่ยนตาม |
| `content/meta.ts` | หมวด, Expert 8 ด้าน, อัปเดตล่าสุดบนหน้าแรก |
| `content/glossary.ts` | คำศัพท์ |
| `lib/calc.ts` | สูตรคำนวณภาษี (มีเทสใน `lib/calc.test.ts`) |
| `lib/search.ts` | ค้นหาภาษาไทย (ตัดคำด้วย `Intl.Segmenter`) |
| `app/experts` | ผู้เชี่ยวชาญล็อกอินเพื่อตอบคำถามและเผยแพร่เป็น FAQ |
| `app/api/ask` | ผู้ช่วย AI (ปิดอยู่จนกว่าจะใส่ API key) |

## ถาม Expert

1. ผู้เรียนพิมพ์คำถาม → ระบบค้นเนื้อหาในห้องเรียนและ FAQ มาให้ก่อน
2. ถ้ายังไม่ตอบโจทย์ → กด "ส่งต่อผู้เชี่ยวชาญ" คำถามเก็บในฐานข้อมูล SQLite (`data/academy.db`)
3. ผู้เชี่ยวชาญเข้า `/experts` ตอบคำถาม และเลือกเผยแพร่เป็น FAQ ในห้องเรียน

บัญชีผู้เชี่ยวชาญถูกสร้างอัตโนมัติครั้งแรกที่เปิดเว็บ ถ้าตั้ง `EXPERT_DEFAULT_PASSWORD` ไว้: `admin` (เห็นทุกหัวข้อ) และ `expert-oil`, `expert-beverage`, `expert-vehicle`, `expert-liquor`, `expert-tobacco`, `expert-service`, `expert-law`, `expert-general` ทุกบัญชีใช้รหัสผ่านเดียวกัน ควรเปลี่ยนก่อนใช้งานจริง

### เปิดผู้ช่วย AI

ใส่ key ของ Claude ใน `.env.local` แล้วเริ่มเว็บใหม่ ปุ่ม "ให้ AI สรุปคำตอบ" จะขึ้นเอง ไม่ต้องแก้โค้ด

```
ANTHROPIC_API_KEY=sk-ant-...
# ไม่บังคับ: เปลี่ยนรุ่น (ค่าเริ่มต้น claude-opus-5-5)
ANTHROPIC_MODEL=claude-sonnet-5-5
```

AI ตอบจากเนื้อหาในห้องเรียนที่ Expert คนนั้นดูแลเท่านั้น และบอกห้องที่ใช้อ้างอิง ข้อความคำถามจะถูกส่งไปประมวลผลที่ Anthropic ควรตรวจกับนโยบายข้อมูลของกรมก่อนเปิดใช้

## ประเด็นที่รอผู้เชี่ยวชาญของกรมตรวจ

ห้องที่มีข้อมูลไม่ตรงกันในเอกสารต้นทางจะมีป้าย "รอตรวจ" สีม่วง ตัวอย่าง:
- Earmark สุรา/ยาสูบ: สไลด์บทบาทฯ ใช้ 17% แต่ผลรวมตามกฎหมายคือ 17.5% (เว็บใช้ 17.5%)
- ภาษีคาร์บอนดีเซล: สไลด์แสดง 0.52 บาท/ลิตร แต่ 0.0027403 × 200 = 0.548
- ตารางรถยนต์ปี 2569: มีทั้งแบบ "E" และ "E+S" (เว็บใช้ E+S)
- อัตราน้ำมันอากาศยาน (4.726 กับ 4.275) และน้ำมัน RD (6.5 กับ 0)
- อัตราเบี้ยปรับมาตรา 140 บางกรณี
